覆盖沪深北A股，先保留基本面、估值与流动性要求，**完整月线KDJ J＜20是技术观察池的硬入口**。在池内逐项观察周线筑底蓄力、相对前20个交易日均量的日线异常放量，以及15分钟MACD DIF/KDJ J顶、底背离。月J≥20的股票不进入主名单；均线尚未转多也可以作为低J观察股。默认深度检查全部基本面/估值初筛合格股票以确认月J，`--limit 0`；15分钟默认检查整个低J池，不要求基本面增速已经加快。

## 电脑上一条命令运行

安装64位Python 3.11或更新版本，下载项目并在项目目录运行：

```bash
python run.py
```

首次启动自动建立环境并安装依赖。macOS可使用 `python3 run.py`。需要能访问包下载源及公开行情网站。

```bash
# 默认检查全部初筛合格股票的月J，并检查整个低J池的15分钟
python run.py

# 仅预检财报和完整日线
python run.py --daily-only

# 小批次网络检查；明确标记为未扫描完整市场
python run.py --limit 3 --refresh

# 扩展15分钟观察到全部基本面/估值初筛合格股，耗时更多
python run.py --minute-scope screened

# 输出另一次报告
python run.py --output reports/my-run
```

交易日09:45:30之后可做盘中扫描；此前没有当天已完成的15分钟K线，程序会报错。休市日使用最近完整交易日。盘中估值使用本次获取的行情，日线使用上一完整交易日，因此10月8日早盘的日线截至9月30日。未完成的当日日线和分时K线均不参与确认。午休期间不构造虚假的K线。

盘中还校验源行情时刻。大量报价仍显示前次收盘时刻时停止排名；个别无法确认新报价的股票列为缺失。源只提供时分秒，完整报价日期仍不能逐股保证；候选15分钟K线则必须覆盖当天的完整截点。

## 你的交易规则

| 层级 | 实现 |
| --- | --- |
| 基本面 | 最新已公告累计营收/归母净利润同比非负，累计与TTM净利润为正，每股经营现金流为正 |
| 估值 | 总市值/TTM归母净利润、PB及同行业正PE中位数；不把动态PE当TTM |
| 流动性 | 最近20个完整交易日平均成交额至少3000万元，避免拿早盘累计成交额与全天门槛比较 |
| 月线入口 | 最近完整月线KDJ J严格小于20；J等于20、超过20或缺失均不入主观察池；基本面改善在池内加分 |
| 周线筑底蓄力观察 | 最近6个完整周同时满足窄幅、低点稳定、收盘守住区间均值、日均量平稳；逐项指标与阈值公开，不能据此证明主力吸筹 |
| 日线异常放量 | 最新完整日线成交量÷此前20个交易日平均成交量，不含检测当日；默认≥2倍标异常，阈值可配置；不拿未完成早盘量与全天均量比较 |
| 日线与15分钟背离 | 默认对整个低J池检查15分钟顶底背离，不限持仓；主报告只展示低J池内背离，池外已检查日线记录仍存完整JSON/CSV；screened可扩展15分钟范围 |
| 另行趋势确认 | 完整日收盘>MA60且MA20较5根前抬升；完整周收盘>MA20且MA20不下降；完整月收盘>MA20。此确认状态不阻止低J观察入池 |
| 持仓战术 | 只有确认持仓、已入低J池且日/周/月趋势全部确认，才增加60分钟结构及30/15分钟战术观察；仍需支撑阻力、量价和价格结构确认 |
| 人工复核 | 扣非、行业景气、订单、公告、负债、股本变化、减持及仓位止损制度 |

MACD为12/26/9 EMA；KDJ为9期RSV、K/D以1/3递推并初始化50、J=3K−2D。背离比较最近两处严格价格枢轴，左右各3根确认；日线和15分钟观察窗120根，最近枢轴不超过12根。因此背离有确认延迟，首根早盘K线不会立即确认刚形成的枢轴。

周线筑底代理的默认条件：6周最高/最低价振幅≤20%，后3周最低价较前3周最低价下探不超过3%，最新周收盘≥6周收盘均值，后3周日均成交量/前3周日均成交量≤1.1。周内成交量除以真实交易日数，避免国庆休市周因交易日少而被误判缩量。这些是透明的研究阈值，未满足只标观察进度，不排除已经入池的低J股票。异常日线放量的默认2倍门槛也是可调整研究阈值。

日线至少250根，周线至少60根，月线至少24个完整月份。按自然日期确认已结束的周/月：10月8日早盘的最近完整周标签为10月2日，真实末根日线仍为9月30日。交易日盘中不纳入当日尚未结束的周/月，收盘后留10分钟更新余量。日线主源取近期640根；备用源尝试东方财富更长历史。

## 报告与完整性

- `results/latest-report.md`：仓库中直接阅读的最新中文报告，Actions自动发布。
- `report.md`：同一版中文报告，包含全部候选与已发现背离的可展开明细。
- `report.html`：候选卡片、覆盖情况及全部已发现背离明细。
- `rankings.csv`：全部基本面/估值/流动性通过且月J＜20的观察候选。
- `observations.csv`：月J入口或其他筛选条件未通过的检查记录。
- `divergences.csv`：日线/15分钟顶底背离、指标值、枢轴、确认时间、是否在低J池及另行趋势确认资格。
- `excluded.csv`：逐股排除原因。
- `report.json`：全部结果、评分分解、原始抓取时间、缓存状态和数据SHA256。

每25只完成一次中间报告。`scan_complete`、`coverage`和错误列表决定是否扫描完整，接口缺失不会被解释成“没有背离”。技术数据不足、停牌、延迟或接口失败会明确标为不完整。退出码0=所请求范围无数据错误，1=部分数据错误，2=核心数据失败；有限批次即使退出0也可能并非完整扫描。

Excel导入CSV时把代码列设为文本，以保留前导0。

## 持仓与阈值

默认没有确认持仓，不把旧聊天中的持股当成今天仍持有。复制 `holdings.example.json` 为本机 `holdings.json`，填入仍持有的六位代码；启动器会自动读取。真实持仓文件已被git忽略，勿手动上传到公开仓库。没有持仓也会得到日线和15分钟观察结果。

`config.json` 是可调整研究阈值：PE TTM≤60、PB≤8、PE/行业中位数≤1.2、行业样本≥5、报告期距今天≤225天。现金流规则不适合直接比较所有金融行业，需专项复核。

评分满分100：累计营收增长10、累计利润增长15、正现金流5、行业相对估值25、均线趋势确认15、利润同比加速5、周线筑底代理15、完整日线异常放量10。月J＜20是入口，不再作为额外加分。分数只表示研究优先级，不代表收益概率或目标价；背离单独列示，不改变入池或趋势确认资格。

机器结果`selection_rule=monthly_j_lt_20`，`eligible`表示观察入池；`strategic_eligible`表示入池后另外通过原有日/周/月均线趋势确认，持仓战术只使用后者。`candidate_count`为全部低J观察候选数，`coverage`另列周线筑底、日线异常放量、低J池15分钟和趋势确认的数量。旧版本的高J战略候选不能当成新规则结果。

## 数据口径

使用新浪全市场分页行情和分时、腾讯近期日线、东方财富数据中心财报，以及AKShare 1.19.1交易日历。日线按腾讯、东财、新浪顺序使用真实备用源；新浪必须返回可验证的前复权因子，缺失时拒绝计算。保留每次切换的原因和数据来源。不需要付费Token，无券商订单接口，也未调用13个LLM。

财报抓取最近8个已结束报告期，按已公告日期过滤，使用字段名映射并检查报告期及分页完整性；缺失值不填零。成功分页最多缓存10分钟，供失败重试补缺，完整历史报表缓存24小时，最新报告期只缓存15分钟。TTM净利润=上年全年+本年累计−上年同期累计，年度报告直接用全年；缺少桥接报告不参与估值。改善只是累计同比增速加快的代理，不等于已证明单季拐点。

新浪市值万元转换为元；腾讯成交额万元转换为元。15分钟原始价格按同日原始/前复权日线比例调整；当天重新锚定复权数据并拒绝缺失因子，避免除权跳空制造背离。最新前复权和重述财报不适合直接当成历史可得数据回测。

公开接口可能延迟、超时、限流或改版，获取时间不等于交易所逐股报价时间。分时必须覆盖实际已完成截点；不能保证毫秒实时，也不承诺每次整批都成功。没有模拟数据回退，也不使用过期缓存掩盖失败。
