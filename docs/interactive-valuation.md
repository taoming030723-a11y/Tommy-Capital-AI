# 每日报告的两个窗口与逐股估值

[打开手机交互中文报告](https://tommy-capital-report.stableokapi18.chatgpt.site)，使用网站所有者的同一ChatGPT账号登录。此地址沿用既有私有网站，手机可直接访问，不要求电脑开机。GitHub Markdown自身不能运行表单，页顶链接会打开该网站。

## 两个直接操作窗口

| 窗口 | 操作 | 每日报告中的效果 |
| --- | --- | --- |
| 填写持仓股票 | 输入名称或六位A股代码，点“确认加入持仓观察” | 持仓身份立即并入每日持续观察表；跨日、跨设备保留 |
| 移出Top10观察 | 输入名称或代码，点“确认移出观察名单” | 移除Top10及手动观察身份；后续报告继续隐藏，可在“已忽略”恢复 |

名称通过东方财富证券搜索核验，只接受A股；有多个匹配时先选择具体代码，不混入同名港股。重复加入已有持仓不会清空成本、股数、日期或备注。详细持仓区仍可编辑及删除已清仓股票。

观察表是“累计Top10至少三次的股票”和“你确认的持仓”的并集。同一代码只显示一次，来源分别标记。三次仍指累计三个不同正式收盘日，不要求连续；手动加入不伪造三次、不改变原始历史、评分、排名或做T资格。

持仓优先于观察忽略：移出Top10不等于清仓，仍保留持仓风险观察。只有在持仓区明确删除，才取消持仓身份；删除后若仍满足且未忽略Top10条件，继续按观察股显示。

私人记录保存在原网站D1数据库，按平台验证的用户身份隔离，revision比较拒绝覆盖另一窗口的新设置。成本、数量、备注不提交公开GitHub。网页偏好不会改写电脑文件或公开云端扫描的偏好文件。

## 每只股票的估值

网页为综合前20、持续观察及持仓的并集显示一份估值表。每日Actions收盘流程也为公开研究榜与公开观察/监控股票附加同口径数据，写入同份JSON、中文报告及日期归档。相关功能使用`web-report/lib/valuation.mjs`，不重算选股分数。

表中列出报告日收盘价与日期、PE(TTM)、PB、近三年正PE中位数、当前历史分位、扣非/归母盈利、经营现金流/归母盈利和综合判断；展开可见依据、数据范围及来源。

| 判断 | 必要条件 |
| --- | --- |
| 相对低估 | 当前PE≤综合参考PE的80%，历史分位≤30%，扣非/归母≥0.7且经营现金流/归母≥0.8 |
| 相对高估 | 当前PE≥综合参考PE的120%，历史分位≥70% |
| 相对合理 | 数据齐全，未达到上述两端条件 |
| 历史PE偏低，兑现待观察 | 历史PE低，但盈利质量或现金流兑现未达到门槛 |
| 历史与基本面估值分歧 | 历史位置与基本面修正方向发生冲突 |
| TTM亏损，PE不适用 | 非正盈利或非正PE不与正盈利期PE直接比较，不用负PE认定低估 |
| 估值待核验 | 缺失、过期、价格不一致、历史或财报证据不足，保留明确原因 |

三年窗口排除估值当日、未来日期、非正PE；至少120个正PE交易日且跨度不少于365天。历史分位采用低于当前PE的样本数，加一半相等样本数，除以样本总数。返回页数或总记录数不完整时拒绝判定。

历史与基本面参考各占50%。基本面参考优先使用原扫描有效同业正PE中位数（至少5个样本），缺少同业时明确改用自身历史中位数，再根据扣非占比、现金流兑现和同期扣非利润率改善作质量修正。质量因子为`clamp(0.6, 1.1, 0.85 + 0.1×[扣非占比≥0.8] + 0.1×[现金转换≥1] + 0.05×[利润率改善] - 0.15×[扣非占比<0.7] - 0.15×[现金转换<0.8])`。综合参考不是DCF内在价值；界面倍数换算区间假设当前TTM盈利不变，不是目标价。

这些阈值是可编辑研究规则，不是经过收益验证的最佳参数，不能保证市场价格会向该区间回归。PE同时受增长、风险和再投资需求影响，现金流修正并未穷尽所有估值因素。金融行业不套用普通企业现金流模型，保留历史位置并标待核验。亏损收窄可以保留原路线研究资格，但综合高低估仍需有证据的正常化盈利/SOTP/EV-Sales，不能硬造正PE。

数据来自东方财富历史估值、业绩报表、利润表及现金流量表。自选股补充财务使用已公告同报告期数据，TTM=本期累计+上年全年−上年同期；公告晚于报告日、同期利润版本不一致、最新财报距报告日超过225天时不补造质量指标。历史PE是供应商当前可取得序列，可能经过追溯更正，不能冒充原时点财报版本用于无偏回测。

参考来源：[东方财富估值分析](https://data.eastmoney.com/gzfx/detail/603127.html)、[Damodaran：PE及基本面关系](https://pages.stern.nyu.edu/~adamodar/pdfiles/pe.pdf)。具体阈值是本项目选择，并非这些来源给出的收益承诺。

## 更新与缺失

网页自动读取已发布的正式收盘报告；估值优先使用随报告发布的同源记录，旧报告没有附加记录时按报告交易日查询。逐股估值失败显示待核验，不改日期或填假值。Actions附加估值有独立时间预算，先在临时目录完成全部报告视图渲染，再替换；源失败或渲染失败不抹掉原扫描结果。

新增私人持仓会每天保留在网页观察表，并查询估值。五周期MACD仍复用原Python已发布结果；私人新增代码不在公开监控范围时，会显示未有结果。完整五周期即时刷新继续在电脑`Start-Report.cmd`内执行，网站不假装公开Actions能读取私有持仓。公网报告、电脑本地数据与网页私有数据的边界保持明确。
