## MA55的16分

- 最近完整周收盘及最新完整日收盘都在已知完整周MA55之上：5分。
- MA55原方向判断：上行4分、走平2分、下行0分。
- 最近6个完整周逐周比较各自MA55：至少4周且连续3周在线上得4分；至少3周且连续2周得2分；其余0分。
- 原严格回踩收回，或重站后下一完整周守住，且MA55不下行：3分。不因同一周期同时出现两个条件而叠加。

若完整周或最新完整日失守MA55，四项正分均为0，保留原2分失守扣分。原入池条件不降低：MA55不下行、周/日在线上、近6周至少3周且连续2周在线上，缺失不通过。高分不覆盖入池门槛。

## 周MACD的6分

标准EMA12/26、DEA9，柱体为`2×(DIF−DEA)`。只比较最近两个完整周，柱体高度及变化均除以最新完整周ATR14；价格单位整体放大不会产生额外分。

| 柱体状态 | 柱体分（上限5） |
| --- | ---: |
| 红柱增强，或由绿转红且增强 | 5 |
| 红柱变化不显著 | 3 |
| 红柱明显衰减 | 1.5 |
| 绿柱绝对值收敛 | 3 |
| 绿柱扩张、红转绿、绿柱变化不显著 | 0 |
| 柱体绝对值≤0.02ATR，或必要数据缺失 | 0 |

“明显”要求周变化绝对值≥0.02ATR，延用原动量判断的ATR显著性下限。红柱区域变化不足阈值时不按增长打满分；微小零轴跳动不按转红打满分。DIF高于DEA至少0.02ATR另1分，因此MACD状态最高6分。旧版1.8分动量不再叠加。

绿柱收敛只是下跌动能减弱；红柱衰减只是上涨动能减弱。两者都不自动生成顶底背离、不授予买点或做T资格。严格枢轴、右侧完整K线、间距、ATR、DIF过滤仍由原算法决定，确认周底背离另最高1分。原确认顶背离扣分、支撑破坏/追高风险扣分保持；动量加权不会取消风险扣分。
