# Windows持仓与MACD监控操作

此窗口维护本机明确持仓，不把聊天中的历史交易当成当前持仓。首次运行默认空持仓。

## 打开窗口

1. 安装Python 3.11或更新版本，安装器勾选Python Launcher；更新或下载本仓库并解压到可写目录。
2. 双击根目录`Start-Report.cmd`或原`Start-Monitor.cmd`，默认打开最新报告。首次启动会建立`.venv`并安装`.[ui]`，需要联网；后续复用环境。
3. 浏览器打开`http://127.0.0.1:8501`。窗口仅监听本机；关闭命令行窗口即停止服务。首次提示若端口被占用，关闭旧窗口再启动。

已有Python环境也可在仓库目录执行：

```powershell
py -3 -m venv .venv
.venv\Scripts\python.exe -m pip install -e ".[ui]"
.venv\Scripts\python.exe -m streamlit run monitor_app.py --server.address 127.0.0.1 --server.port 8501
```

本次在Linux运行了真实Streamlit服务启动、HTTP健康检查及AppTest交互测试；没有在你的Windows电脑上执行安装，不能把这些检查说成Windows实机验收。

## 最新报告与原两个页面

“最新报告”页已集成忽略/恢复按钮、手动观察输入框、持仓编辑器及五周期监控。可在同一报告页面完成操作。详见[报告内操作说明](report-controls.md)。本机偏好保存在`.tommy/report-controls.json`，与GitHub云端设置区分；同步只下载公开报告，不上传私有名单。

“持续Top10观察池”显示累计三个不同正式收盘日进入Top10且未忽略的股票，不要求连续。侧栏“同步公开观察名单与忽略设置”只下载固定Git提交中的公开累计历史、用户忽略设置和已验证收盘摘要；不会上传任何本机文件。不同评分版本的历史榜单不重新排序。

“我的实际持仓”可新增、选择已有代码编辑、删除已清仓股票。输入六位A股代码，系统尝试用实际报价接口识别名称；接口暂不可用时名称标待核验，仍可仅保存代码。成本、股数、日期、备注均可空。点击“保存持仓”后再点击侧栏“一键刷新全部重点监控”。两个窗口并发编辑时采用版本校验，过期编辑不会覆盖新记录，可点“重新加载持仓编辑版本”。

持仓优先于观察忽略：已忽略的股票只要仍在本机持仓，就继续监控；删除持仓后若仍满足公开观察条件则作为观察股保留，否则退出当前监控。相同股票复用同一份行情和指标，显示两个身份。

“只看出现警报的股票”筛选动能变化、背离或风险异常。展开每只股票可看五个周期的截止时间、来源、枢轴、柱波峰值、DIF、确认时间、缺失及事件历史。行情不足显示无法判断，不当作无信号。公开观察输入暂不可用时，本机已保存持仓仍可独立刷新，观察池范围异常会明确显示。

## 文件及隐私

| 文件 | 用途 | 是否自动公开 |
| --- | --- | --- |
| `holdings.json` | 当前持仓、可选成本/股数/日期/备注 | 否，默认gitignore |
| `.tommy/monitor/state.json` | 本机五周期已观察K线和追加事件、可选浮盈状态 | 否 |
| `.tommy/monitor/latest.json` | 本机最近监控结果 | 否 |
| `.tommy/monitor/archives/` | 手动重建前的旧事件归档 | 否 |
| `.tommy/public-inputs/<commit>/` | 下载的公开观察名单快照 | 仅下载，不上传 |
| `results/macd-event-state.json` | 云端公开Top10观察股事件去重状态 | 是；禁止成本、数量、持仓身份和浮盈 |

`holdings.json`兼容原格式`{"holdings":["600000"]}`；新窗口保存为schema2的对象列表。原全市场扫描`--holdings 路径`继续读取代码；独立命令行也支持：

```powershell
.venv\Scripts\python.exe -m tommy_capital.monitor --holdings holdings.json --out .tommy/manual
```

本模块不提供云端持仓管理或上传入口。GitHub Actions不能读取本机文件；公开发布器会拒绝带个人持仓/浮盈字段的MACD结果。不要自行把私有文件加入Git，公开仓库的旧提交也可能保留历史文件。

## 浮盈起点与数据变化

只填代码时不计算浮盈，MACD分析仍正常。填写成本可计算实际未复权报价相对用户成本的浮盈；有股数还可计算金额。最大浮盈只从首次实际记录开始，回撤给出相对成本的百分点和相对已观察最高价格的比例，不假定曾经持有的最高价。费用、现金分红、送转和真实历史仓位变化未计入；成本、数量或建仓日期改变时重建观察基准。

监测到历史价格/复权变化会冻结对应周期旧事件，不静默重画。长时间未刷新或忽略后恢复时，若公开接口窗口已不覆盖上次K线，该周期也明确标历史缺口，不跨缺口拼接EMA；其他完整周期继续检查。确认变化原因后，在侧栏展开“历史复权或配置变化后的状态重建”，勾选核对项，点“归档旧监控状态”，再刷新。原事件保存在归档，新基准从头记录，不能将新结果倒写成旧交易时点已知。调整监控配置也要求建立独立状态。

## 行情及任务

本机刷新只获取观察池与当前持仓并集，不扫描全市场。没有新增盘中自动轮询任务；你可手动刷新。云端沿用15:05收盘计划和原补检，在原扫描结束后独立运行公开重点监控；GitHub排队和数据源延迟仍可能影响完成时间。

日线沿用多源真实前复权数据及至少250根要求；15/30/60分钟用新浪原始分时和逐日原始/前复权日线因子配对。120分钟由完整60分钟合成上午和下午各一根，没有宣称存在稳定的直接120分钟公共接口。停牌、缺根、历史不够、日期或复权不匹配均显示无法判断。

MACD统一EMA12/26、DEA9，柱为`2×(DIF−DEA)`。动能减弱、疑似与严格确认分别显示；15分钟单独顶背离不会自动升级成整轮趋势结束。部分减仓三分之一至一半仅是供本人判断的方案，没有下单能力。

## 离线演示与测试

```powershell
.venv\Scripts\python.exe -m pip install -e ".[test,ui]"
.venv\Scripts\python.exe -m pytest -q
.venv\Scripts\python.exe -m tommy_capital.monitor_example
```

演示输出在`.tommy/offline-example/`，使用带SHA256的已收到真实历史日线，分钟数据未附则明确缺失。它不是实时行情、当前持仓或收益回测，不计入正式Top10历史。算法、配置、模型变化见[监控与v8说明](macd-monitor-v8.md)。
