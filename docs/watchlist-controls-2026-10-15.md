# MA55加权与观察名单管理

本页保留`weekly_ma55_50_50_v7`历史参数。之后用户进一步授权仅周/月评分、强化MA55入池及独立MACD监控，现行v8见[升级说明](macd-monitor-v8.md)。下述历史版本按提高周MA55权重的要求，MA55专项8→12分，周线总分18→22分；月线18→16、日线10→8，分时仍为60分钟2、30分钟1、15分钟1。技术50分、基本面50分保持。

| 周MA55专项 | 满分 | 规则 |
| --- | ---: | --- |
| 当前位置 | 4 | 最新完整周与最新完整日均收在已知完整周MA55之上 |
| MA55方向 | 3 | 上行3、走平1.5、下行0，原斜率与ATR阈值保持 |
| 近期站稳 | 3 | 至少4/6周在线上且连续3周守住得3；至少3/6且连续2周得1.5 |

专项占技术分24%、周分54.5%。任一当前收盘不在线上则专项12分不授予，并扣周线2分。其他周分仍为周结构2、短均线1、KDJ1、完整周量4、MACD动量1、确认底背离1。月线16分为月J路径3、低点稳定1、短均线4、KDJ2、月量4、MACD动量1、确认底背离1；日线8分为短均线2、价格启动或真实支撑收回3、KDJ1、MACD动量1、确认底背离1。所有原始阈值、完整周期、前复权、时效、A/B入口、基本面估值与T权限保持。

## 自行忽略与恢复

在中文报告的累计前10观察表标题旁点击“忽略/恢复”，进入[观察名单管理](https://github.com/taoming030723-a11y/Tommy-Capital-AI/actions/workflows/watchlist.yml)，点击Run workflow，选择“忽略”或“恢复”，输入六位股票代码（保留前导0）并提交。管理运行只读已有真实报告，不请求行情，不重扫全市场。完成后返回中文报告查看更新。

设置保存在`operations/watchlist-preferences.json`，初始为空，不预先替用户忽略任何股票：

```json
{
  "schema": 1,
  "ignored_codes": []
}
```

可直接编辑该文件，把自己选择的六位字符串代码放入数组，提交后也会刷新当前观察表；移出数组即恢复。无效格式、重复代码或丢失前导0会被校验拒绝，不把错误设置当成有效选择。

忽略只隐藏累计观察表，综合前20仍根据真实评分生成，扫描范围和入榜历史不变。原要求是累计三个不同正式收盘日，继续保持这个口径；此次“忽略”功能不重置累计，也不把门槛改为连续交易日。恢复时沿用原真实次数。JSON记录`all_rows`保留有实际数据来源的原观察行，`rows`是当前可见行，`preferences`、哈希及`suppressed_count`记录应用的选择。配置损坏时观察表明确显示异常，不擅自将被忽略股票重新放回。

## 显示刷新与真实行情区分

管理运行同时更新latest与对应日期closing归档的观察表显示及机器摘要的`top10_tracking`，不修改原扫描时间、行情日、评分版本、覆盖、候选数、Top20、价格、日量或研究结论。用户偏好刷新另记`preferences_updated_at/by`，不能把此时间当作市场扫描完成时间。原Actions附件保留扫描时的快照；之后的用户显示偏好更新有独立提交记录。

新权重从下一次真实扫描开始计算，本次设置功能不会把今天的v6报告伪装成v7，也不会为重算而启动额外全市场扫描。手动忽略/恢复仅有权限的仓库用户可以执行；程序只提交偏好文件及已核验报告的观察表部分，使用最新main父提交和非强制更新，遇到并发更新重读新报告与偏好。扫描最终发布也重读当前偏好，避免扫描期间作出的忽略选择被较晚发布覆盖。
