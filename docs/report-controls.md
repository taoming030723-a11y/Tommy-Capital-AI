# 在最新报告里管理观察和持仓

新版手机报告顶部提供“填写持仓股票”和“移出Top10观察”两个窗口，支持名称或代码；每只研究/观察/持仓股票增加基本面与三年历史PE综合估值。操作与缺失处理见[两个窗口与逐股估值](interactive-valuation.md)。

## 手机直接打开

[打开HTTPS交互报告](https://tommy-capital-report.stableokapi18.chatgpt.site)。用同一ChatGPT账号登录即可，网站仅所有者可访问；手机5G/Wi-Fi均可，不需要电脑先开机。公开GitHub报告页顶和之后的HTML报告均使用这个地址。

网页里可以忽略/恢复Top10观察、手动添加/移除观察、添加/修改/删除持仓并导出私人名单。设置持久保存在受登录保护的D1私有数据库，以平台用户ID隔离，支持同一账号跨设备使用；不写进公开仓库、不覆盖电脑文件。网页偏好、电脑偏好和原GitHub云端忽略设置各自独立；云端设置继续使用报告里的“云端忽略/恢复”入口。

手机报告新增[六周期技术评估](focused-technical-review.md)，可直接刷新当前观察与持仓并集，独立显示技术行情日与程序买点条件，不重扫全市场。原Python五周期事件表保留已发布确认和行情时间。ChatGPT解释需API凭据，未配置时显示程序评估；网页不推断历史持仓、最大浮盈或做T资格。

## 电脑完整监控

更新或下载本仓库后，在Windows双击根目录 **`Start-Report.cmd`**（原`Start-Monitor.cmd`也可），默认打开“最新报告”。需要Python 3.11以上版本，首次启动安装依赖。浏览器地址是`http://127.0.0.1:8501/?page=report`，仅本机监听。

报告页集中提供：

| 位置 | 操作 | 保存及影响 |
| --- | --- | --- |
| 最新报告顶部 | 同步最新报告、刷新观察与持仓监控 | 下载同一Git提交的公开中文/JSON/累计历史/忽略设置；监控只请求当前重点并集 |
| 累计Top10观察表下面 | 每只股票的“忽略”按钮 | 立即隐藏本机观察行及其Top10监控身份；累计次数和Top20不变 |
| 已忽略股票 | 选择代码、恢复观察 | 保留原累计次数，重新加入本机Top10观察范围 |
| 手动添加观察股票 | 输入六位代码、加入观察、移除观察 | 自动尝试核验名称；独立观察身份，不增加Top10次数，不认定实际持仓 |
| 我的实际持仓 | 在报告内新增、选择编辑、删除 | 复用原持仓编辑器；成本、数量、日期、备注可空 |
| 多周期MACD | 查看五周期状态和具体依据 | 显示真实检查/行情时间、缺失和事件，报告数值不重算 |

同一代码可以有Top10观察、手动观察、持仓三个身份，刷新时只抓取和分析一次。忽略只移除Top10身份；显式手动观察和实际持仓独立保留。移除手动观察后若仍符合Top10或仍持仓则继续监控；手动观察本身不授予做T资格。新添加后点击“刷新观察与持仓监控”获取数据，未刷新时明确显示等待，不能冒用旧数据。

本机忽略、恢复和手动观察存于`.tommy/report-controls.json`，重开窗口、同步新报告后仍保留。持仓继续保存在`holdings.json`，两者默认不提交Git。同步公开输入只下载，不上传这两个文件。窗口和命令行的已有持仓格式继续兼容。

**本机设置与云端设置有明确区别。** 报告内的直接操作控制本机交互版及本机重点监控；云端自动扫描继续读取仓库`operations/watchlist-preferences.json`。需要各设备和云端同时忽略时，使用报告中的“云端忽略/恢复”入口，经GitHub原有登录权限执行已有观察名单工作流，再在窗口点同步。程序不会把成本、数量或手动名单公开上传，也不要求把GitHub令牌放进报告。

GitHub的`latest-report.md`是只读Markdown，不能执行表单。它的顶部现在提供HTTPS私有网页入口；手机可直接访问。`127.0.0.1`始终指当前设备自身，只有在电脑启动本机程序后，才能从同一电脑打开这个本机地址。手机不要再使用旧的127.0.0.1报告链接。

交互版显示已发布报告的真实数据日、原扫描完成时间和原评分版本；不会把昨日报告改称今日报告，也不根据现行代码重算旧榜。窗口默认新增“最新报告”页，原“持续Top10观察池”和“我的实际持仓”页仍可单独使用。旧报告与当前日期归档仅补操作入口，市场日期、计数、排名、评分和机器摘要均保留。
