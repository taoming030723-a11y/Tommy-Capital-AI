# 多周期右侧反转机会池（独立研究路线C）

版本`right_side_reversal_v1`。生产评分仍是`weekly_ma55_macd_50_50_v9`：基本面50、月线20、周线30，周MA55专项16分。C不会改变A/B资格，不向原Top20补人，不计入原Top10累计，不自动买入、卖出或获得做T资格。

## 复用与边界

复用`technical.indicators`、完整周/月聚合、RVOL20、`patterns.macro_profile`、`weekly_ma55_observation`、`kd_state.classify_kd`、原基本面检查、证据内在价值和研究价格窗口函数。没有另造MACD背离判定，也不改变`monitor_risk`。仓库没有独立量价效率模块，本次只增加必要的RVOL、CLV、回调量、上影线与方向性ATR推进/RVOL描述；不扩展成资金流/Amihud系统。

`strategic_technical`在同一组已计算的d/w/m上生成可选`reversal_features`，无新增网络请求。新配置/特征失败只让C标未知，不丢弃原卡片，也不改变原覆盖数或扫描状态。原已通过数据核验范围外的股票继续计入原技术缺失数，不能称C已完整覆盖全A股。

## 算法与公式

所有阈值在独立研究配置中，不是回测最优值，不会自动训练。

| 证据类别 | 判定方法 |
| --- | --- |
| 长期结构 | 同时检查此前6/12/18个完整月。区间高点必须先于低点，下降跨度至少3个月、跌幅至少20%；低点之后至少已有2个完整月没有更低低点。它是区间低点代理，不替代严格MACD枢轴规则。 |
| 月线修复 | 最近3月K持续改善、当前K>D、D不再明显下降；DIF改善，且DIF>DEA或柱体比上月改善；价格站上月MA5，近3月低点相对前3月稳定。J不单独投票，J>80也不直接触发排除。 |
| 周线转强 | 周收盘位于MA5/13/55上方，MACD差值为正且DIF不下降，KD偏多。MA55方向严格复用最近3周跨度/ATR的原算法；站上线与方向分开显示。 |
| 周线较强 | 以上条件加MA55走平或上行、6周至少3周在线上且连续至少2周、低点抬高、MA5/13改善及DIF>0。 |
| 日线整理 | 最近60交易日有先低后高的至少15%首轮上涨；高点后已至少3日，回撤不超过15%，低点稳定，MA5/13间距不超过4%，价格保持MA13附近，K回到中间区间。 |
| 再次启动确认 | 收盘突破此前10日压力且RVOL20≥1.5、收盘位置≥0.65；或复用真实均线回踩收回，回调量较此前20日安静、当前RVOL≥1。Stage 4还须日MACD有效改善及KD从中间区间转强。红柱变短不是独立启动依据。 |
| 风险隔离 | 过度延伸（距日MA13≥12%且≥2ATR）、明显上涨后高位放量及多次长上影、突破失败进入风险观察，不占C机会Top20；两根完整日收盘跌破它们之前已知支撑，或周线重新转弱，可标结构失效。 |

RVOL20=`当前完整周期成交量/此前20个完整同周期均量`，分母排除当前周期。CLV=`2×(close−low)/(high−low)−1`，零振幅返回未知。方向性量价代理=`(close−previous_close)/ATR14/max(RVOL20,0.25)`，用于解释，不计生产分，也不等于净买入资金。不同周期分别按自身历史比较，不跨周期直接相加原始成交量。

## 阶段、排序与财务约束

| 阶段 | 含义 |
| --- | --- |
| 1 | 长期下跌后月线修复，周线尚未确认。 |
| 2 | 周线率先转强；MA55可能仍下降或站稳时间不足。 |
| 3 | 周线证据较强，日线整理或回踩/突破观察。 |
| 4 | 阶段3基础上，原基本面A/B核验、周MA55门槛、周结构/日趋势、原数据完整性要求、日线量价/KD/MACD和独立估值证据全部通过；仍无交易授权。 |
| 5 | 价格/周线结构失效，或已核实重大经营风险。仅有财务字段缺失不判企业恶化。 |

**C不重套A/B的月J窗口，也不改写A/B交易资格。** J已脱离旧窗口的股票可按C独立月线修复条件进入研究；符合上述严格条件时可标C阶段4，但原资格、分数及做T权限保持原值。完整性检查只读复用`balanced_score`，不把重算的分数写回生产卡片。阶段1–3不表示可以买入。

独立排序依次比较阶段、财务核验状态、周MA55连续守住数量、最近6周守住数量、代码。没有把高度相关的均线/KDJ/MACD反复相加，没有新综合分。高估/待核验与技术阶段分栏显示；未通过投资核验时明确标限制，不把技术研究名单当成投资推荐。

财务必须有真实营收、归母/扣非、CFO当前与TTM、同比数据、已知公告日期及报表版本匹配；原A基本面不通过且无已核验B基本面例外则不通过财务核验。内在价值复用现有三情景估值，Stage 4要求原20%安全边际且无明显模型分歧，历史PE或行业PE不能冒充内在价值。

`operations/reversal-reviews.json`默认空。人工公司复核须逐项明确`business_continuity`、`debt`、`goodwill`、`litigation`、`operating_improvement`（true表示该项复核通过），并提供`as_of`和`sources`。来源需含HTTPS URL、发布日期、SHA256、`verification=verified`，还必须与本次`leading_evidence.records`中**已经实际抓取核对**的来源URL和哈希匹配；不能只在JSON写个verified就自证。资料最多有效90天，未来日期无效。

名称/行业属于连锁药房、药店、医药商业时另需`store_productivity`与`lease_liabilities`；这是行业规则，不匹配证券代码，不给其他行业套药房条件。默认没有经营、债务/商誉/诉讼证据时为“待核验”，不会假设业务恶化或风险不存在。C内在价值模型沿用`operations/investment-research.json`和已核验估值证据，不提高原基本面分。

## 完整K线、口径和缺失

标准MACD为EMA12−EMA26，DEA9，柱为2×(DIF−DEA)；KDJ为(9,3,3)，原50种子。截图的(10,23,9)不参与计算。

正式月线和周线只接受不晚于已知完成截止的月末/周五标签，日线只接受已收盘交易日；14:34回放排除当天日线、形成中周线和形成中月份。价格和均线使用同一qfq锚点。历史前缀截断在指标计算之前；右侧低点确认只用当时已有完整月。新数据不会改写旧事件或冻结快照。

不足250日/60周/24完整月、零成交、参数混用、ATR为零/非有限等为“无法判断”，不能填零。24个月不足以算月MA55时保留未知及距离缺失；不为全市场再发一轮长历史请求，不把它伪装成均线上行。形态未形成与数据未知分别统计。

## 运行与产物

现有15:05及补检计划、`--limit 0`保持。合并后主扫描附加C特征；在原估值研究步骤后执行：

```bash
python -m tommy_capital.reversal_research --attach reports/latest
```

完整报告与机器摘要新增`reversal_opportunities`，附件有`reversal-opportunities.json`。中文/HTML及现有动态报告渲染同一独立章节。未合并前不会更改正式报告。

`reversal-event-state.json`在独立结果路径保存，不使用Top10历史作为C名单。相同代码/区间低点/模型参数/阶段反复刷新不会重复报警；阶段变化、失效和恢复保留事件。条件消失记“条件不再满足”，不把它伪称结构失效；数据暂缺不清除旧事件。旧日期、同日较旧扫描不能覆盖新状态；事件哈希和私有字段均检查。

真实观察时刻的快照保存到`research/reversal/<实际观察日期>/<SHA256>.json`，包含数据日、源扫描、版本/配置及前20研究名单。研究今天重放旧数据时仍按今天冻结，不回填成旧日已发现的信号。它与原研究快照、Top10计数和持仓完全分开。


冻结样本已核对当天真实收盘报价和日线，独立周/月线又与日线重叠OHLC校验；CSV及真实交易日历各有SHA256。小样本采集是显式命令，不会由调度器每15分钟触发。原免费源不能提供更长可靠日线时，真实返回约640根就保留该长度，不用不同复权锚点拼接更早历史。

研究用固定每21个真实交易日取点，比较C技术研究池、简单周MA55、较严格三周期确认；同一股票/变体60个交易日内重叠信号抑制。5/10/20/60日从信号之后首个真实交易日开盘观察，20bp/边为成本假设。停牌/缺交易日、零成交和首日单价K线保持未知；非单价涨跌停同样未证明可成交，因此不称真实交易收益。收益、收盘最大回撤与入场后最低价不利变化分开保存。

当前历史全市场成分、退市股、当时公告版本财报和估值快照不充分，不能重建严格A/B历史策略；该比较明确标不可评价，不用今天财报回填。当前qfq历史不是当时留存的复权锚点，六只存续股票也有幸存者偏差。所有结果保持`unvalidated_out_of_sample`，不证明收益能力，不触发权重训练或生产启用。
