# 周MA55作为建仓结构的重要参照

用户明确说明昭衍新药、特变电工图中的B/T为历史建仓节点，并强调当时周MA55的状态、股价最近几个周期处于其上方，是重要分析依据。由此把偏好细化为：月线完成原低位/恢复筛选后，重点研究周MA55转稳或上行、价格重站并守住或回踩收回的形态，再结合周月量、MACD/KDJ和日线位置。股票名称和历史交易标记不参与评分，不自动认定当前持仓。

`scoring_version=weekly_ma55_50_50_v6`。基本面50分、技术50分保持，月18、周18、日10、60/30/15分钟为2/1/1。仅在原周18分内重分配：

| 周线分项 | 分数 | 计算 |
| --- | ---: | --- |
| MA55当前位置 | 2 | 最新完整周、最新完整日收盘同时高于最近完整周MA55 |
| MA55方向 | 2 | 最近3周跨度的MA55变化/最新周ATR≥0.05得2，绝对值<0.05走平得1，≤-0.05下行得0 |
| 最近6周站稳程度 | 2 | 至少4/6周收于各自当周MA55上，且连续3周守住得2；至少3/6且连续2周得1 |
| 回踩或重站确认 | 2 | 最近3个完整周真实回踩后收回，或最近6个完整周曾重站、下一完整周守住且此后未收破；MA55须非下行 |
| 原周结构 | 2 | 原筑底/低点抬高/波动收敛/平台突破规则，权重从4改为2 |
| 短均线结构 | 1 | 原MA5/13/20四分项按比例缩至1分 |
| KDJ恢复 | 1 | 原J上升、K/D转强、低位或近期金叉三分项按比例缩至1分 |
| 完整周成交量 | 4 | 最新完整周量/此前20个完整周均量，排除检测周；原规则保持 |
| MACD动量 | 1 | 原ATR阈值和两种动量条件，最高1分 |
| 确认MACD底背离 | 1 | 原全部枢轴、间距、幅度、同侧零轴和右侧确认条件保持 |

MA55专项共8分，占周分44.4%、技术分16%。方向、站稳与回踩分仅在当前周/日同时位于线上时授予；任一收盘≤已知完整周MA55，则专项8分均不授予，另扣周线2分。单根上穿不会取得站稳或已确认回踩分。MA55下行且价格暂在线上也不会得到方向或回踩确认分。周线总分仍限制在0～18；原大周期扩张/支撑风险及顶背离扣分继续保持。

周线MA55需要真实完整周历史。原最低60周可提供最近6根各自对应的MA55，不增加原最低历史门槛。方向取最近完整周与往前3周的均线差，单位是最新完整周ATR；近6周每根收盘都与它自己当周的MA55比较。历史位置、方向和确认不纳入未结束周。最新完整日收盘另外与最近已知完整周MA55比较，标明是日价参照，不生成本周预测MA55。

真实回踩要求前根收于MA55上、事件周MA55不比前根下降超过0.01个事件周ATR，最低价确实触及该线、下破不超过0.5个事件周ATR，收盘回在线上并超过前根收盘0.02个事件周ATR。之后至观察时的完整周不得收破。重站要求前根收盘≤其当周MA55、事件根收盘高于其当周MA55至少0.05个事件周ATR且收盘位置≥0.65，下一完整周继续收于其当周MA55上；随后不得收破。事件阈值使用事件当时ATR，不借用后来ATR反推历史确认。

`macro_profile.weekly_ma55`保存版本、最近完整周、6周逐根日期/收盘/最低价/当周MA55/乖离、上方周数、连续周数、斜率与回踩/重站确认日期。新版报告前20逐股理由加入周MA55方向、近6周位置、连续站稳周数及最新日收盘距线。仍只有扫描概况、综合前20、累计前10跟踪三张表，再按顺序写理由，不额外铺开数百只股票。

原A/B月J路径、基本面估值、周日战略/执行确认、严格MACD背离、当前持仓T确认、复权与时效均保持；MA55高分不绕过这些要求。旧附件只有最近一根MA55时不能复原6周历史，禁止用今天均线补填；模型复核必须有新版逐周记录。历史最终报告和前10累计台账不因此改写，下一次真实扫描产生新版本结果。

验证：283项回归通过，涵盖逐周使用当周均线、一次上穿与连续站稳的区分、真实触及而非仅站在线上、重站后的下一完整周确认、后来收破的失效、事件阈值不使用后来ATR、最新日跌回线下的扣分、历史缺失不补分以及形成中周线不参与。另用10月14日已核验的两只股票真实前复权周线（各299个完整周、截止10月9日）重算最近6根MA55，与各自最近55根实际收盘均值逐根一致；这只是指标校验，不把历史建仓图当作今天的买点或新收盘报告。
