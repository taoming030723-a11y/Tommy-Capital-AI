## 复现及使用

```bash
python -m pip install -e '.[test,ui]'
python -m pytest -q
node --test web-report/tests/*.test.mjs
python scripts/validate-reversal.py --out reports/reversal-validation
```

本地结果为`validation.json`、`price-study.json`；有原完整报告时可增加`--baseline-report <report.json>`，生成带独立C板块的中文/HTML/JSON预览。CI会重放冻结真实样本并上传`route-c-frozen-real-validation`附件，避免依赖不稳定实时接口来“造通过”。

合并后，现有收盘流程自动附加C特征及独立章节，仍最多显示20只，不填充原Top20。详细算法、经营证据配置、事件去重、缺失处理及手动采集说明见[使用文档](right-side-reversal.md)。固定验证JSON及完整价格研究见[evidence目录](evidence/)。
