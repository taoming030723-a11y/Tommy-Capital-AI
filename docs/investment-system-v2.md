真实验证入口另外修复两处前置障碍：安装已有UI测试依赖，手动验证按`workflow_dispatch`检查日历，不误走有日期和次数限制的补启动请求。验证工作流新增实际启动/完成状态维护，旧运行不能覆盖新运行。旧报告的行情日和原机器数据不改写；网页根据真实状态显示“历史报告／当天生成失败／正在生成”，不把旧数据标为当天推荐。

报价、技术、财报、估值和AI完成度分别显示。缺口分类为历史长度不足、行情日期滞后、复权核验失败、行情源不可用和未分类；输出`retry-queue.json`，包含已发生的尝试和可重试标记。扫描器原有逐股恢复和全局重试继续执行，队列不声称已经补齐缺口。历史不足不能一律叫作新股，也不能靠重试补造历史。估值覆盖另分扣非/现金流证据不足及价格/历史源不足；不能将缺财报当作接口故障。未配置OpenAI时为程序规则分析，模型解释完成数为0。

## 如何使用网页

1. 用创建网站的同一ChatGPT账号打开[交互报告](https://tommy-capital-report.stableokapi18.chatgpt.site)，选择“估值与资金”。原最新报告、持续观察、持仓页面照常使用。
2. 在原持仓页填写六位代码，可不填成本和数量；增加/删除仅修改私人持仓。若要计算账户权重，则需所有真实股数、同日未复权现价和明确可投资现金，缺少任何一项都不显示完整账户比例。
3. 在估值页填写研究对象、中性/悲观/乐观假设、当前正常化利润、合理倍数及来源。页面注明金额单位；手填假设均标“用户假设，未经独立核验”，不反写公开估值、Top10次数或排名。
4. 记录投资理由、下一次财报要核对的事实、足以推翻假设的条件和复核日期。修改保留历史，不把假设当成基本面已恶化。
5. 资金设置只填可承担投资风险的资金。输入进场/失效价、允许单笔风险及单股上限，获得受股数单位约束的股数上限参考；跳空、涨跌停和无法成交可能使实际损失超过计算值。
6. 券商流水只填**已实现、扣费后净额**和唯一流水号。未实现盈亏不结算；每月最后一周星期一按已确认完整期间的正净额提取10%，亏损不提取，重复结算被拒绝。既定10月观察安排保留。已结算期间不能再回填/撤销旧流水，补正应录入后续期间并写明依据。
7. 录入账户权益及期间入出金，明确确认资金流完整性。观察净值从首次记录开始，使用有时间戳资金流的Modified Dietz近似；图示回撤仅限已观察点，不能还原过去真实账户最大回撤。私人页面支持JSON导出备份。

同一股票在持仓及观察池仅分析一次、显示双身份。原忽略/恢复及北交所代码规则不变。新私人API按平台实际身份隔离、检查同源请求、revision和旧值比较后写入；不信任客户端自报用户ID，不向公开GitHub同步成本、数量、现金、流水。网页私有数据与Windows本机文件仍分别保存；`holdings.json`及`--holdings`继续兼容。

## 估值依据和单位

公开研究输入位于`operations/investment-research.json`（默认空的`companies`），阈值位于`investment-config.json`。所有金额在Python中均为人民币元，每股价值通过实际市值/现价推导的股数计算，不默认为固定股本。每家公司`models`可按优先次序登记方法，第一个完整模型为主模型；多个模型中性估值差距过大时单独提示，不强行取平均。

每个模型需`as_of`、`reviewed=true`、`assumption_basis`、`source_ids`及`scenarios.bear/base/bull`。来源必须存在于该股本次已抓取核对的`leading_evidence.records`，包含已验证状态、HTTPS原文、发布日期和SHA256，且至少一个为`field=valuation_basis`。产品交付/上市事实不能直接替代盈利、现金流和倍数依据。模型日期不得未来，默认有效期90天。不能在输入文件中自己写“verified”绕过原始网页核验。

| method | 各情景所需字段 |
| --- | --- |
| `normalized_profit` | `normalized_profit_cny`、`fair_pe`；反向估值另需模型级当前`current_normalized_profit_cny`，不能拿未来中性利润充当当前利润 |
| `fcff_dcf` | `fcff_cny`年度列表、`wacc`、`terminal_growth`，加下述企业转股权调整 |
| `fcfe_dcf` | `fcfe_cny`年度列表、`cost_of_equity`、`terminal_growth`；不再扣净债务 |
| `sotp` | 各分部`name`、`basis=enterprise_value`、`value_cny`，加企业转股权调整；不混用分部股权/企业价值 |
| `ev_sales` | `revenue_cny`、`ev_sales`，加企业转股权调整 |
| `pb_roe` | `common_book_equity_cny`、`normalized_roe`、`cost_of_equity`、`terminal_growth`；金融企业仅走该专用研究方法 |

企业转股权调整必须明确`net_debt_cny`、`minority_interest_cny`、`preferred_equity_cny`、`nonoperating_assets_cny`，不能缺失当零。DCF现金流与折现率匹配、折现率高于永续增长率；现金流预测和终值占比保留，假设不是承诺。三情景需有序，中性价值为正。

安全边际=`1−价格/中性价值`，与上涨空间`中性价值/价格−1`不同；悲观潜在下行单列。默认安全边际20%、高估价格/价值1.2倍仅为可编辑研究阈值，不是统计置信区间或跌幅上限。证据或财务不齐返回“无法判断”，原三年PE参考独立保留、不能冒充DCF。

当前扫描尚不自动取得全部企业的NOPAT、期初/期末调整投入资本及维持性资本开支，因此大部分ROIC和完整DCF仍会未知。新增公式和证据通道不代表已替全市场完成财务建模。经营现金流减总资本开支的FCF与维持资本开支后现金分开，金融行业不套普通CFO/ROIC逻辑。

## 独立前瞻验证

保留生产冻结快照和哈希。增加独立实验：原v9、MA55降为12并向周量/结构重分配4分、移除周柱体并重分配5分、基本面+MA55简化对照。变体都只在已核验候选池排序，不补造被生产入口排除的股票；因此**不能据此验证或放宽原MA55入池门槛**。实验采用真实生成时钟，不回填成此前已经知道的名单，不参与生产排名。

评价从决策后首个真实交易日开盘开始，观察1/5/20/60交易日；成本假设每边20bp，不保证可成交。沪深300和中证500基准使用同样起止窗口的真实指数价格；指数缺日保留缺失，不能拿银行个股000300代替指数。股票前复权与价格指数的比较未纳入完整分红总回报，不标作真实策略alpha。最大回撤是每只股票窗口内收盘轨迹的回撤，不冒充组合回撤。

`walk_forward_splits`提供120日训练、20日测试及至少60日标签隔离工具；**没有自动优化权重，也尚未完成足够的样本外实证**。当前缺乏完整历史退市/停牌样本和公告时点财报库，未解决幸存者偏差；没有完整交易/涨跌停成交模拟。所有结果保留`unvalidated_out_of_sample`。跨版本Top10累计照常保留，新增当前版本次数只作分解，不重写历史，不把不同版本当等价能力证据。
